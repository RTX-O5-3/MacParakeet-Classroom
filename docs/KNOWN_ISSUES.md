# 已知问题

## 开发版启动方式与数据目录

`scripts/dev/run_app.sh` 会为启动的开发版指定独立数据目录。
直接从 Finder 或启动台打开复制出来的开发版 App 时，这个启动参数可能缺失，
从而使用原 MacParakeet 的数据目录。与原版共存时，请通过脚本启动，避免混用历史和词表。

## 回顾与标记

字幕回顾是有长度上限的近期历史视图。旧内容可能从回顾视图中移出。
长时间录制以及不同触控板／滚轮设备上的回看体验仍需继续验证。

最终文本中的重点标记按点击时间与录制时长估计位置，不对应精确的词级时间戳。

## 专业术语与词汇增强

打开增强开关并不等于增强已经生效：词表必须非空、词条启用、引擎支持，
而且 CTC sidecar 必须准备完成。专业术语的转写结果仍可能出错。

## 安装方式

当前仓库提供源码，尚未发布供同学直接下载运行的安装包。
